# Telegram-бот для записи клиентов

Демо-бот для барбершопа: клиент записывается на услугу прямо в Telegram, а владелец получает уведомление. Легко переделывается под любого мастера: салон красоты, репетитора, массажиста, студию маникюра.

## Что умеет

- 📅 Запись за 3 шага: услуга → день → время → подтверждение
- 🚫 Защита от двойной записи: одно время нельзя занять дважды
- 📋 «Мои записи»: клиент видит свои записи и может их отменить
- 🔔 Уведомления владельцу о новых записях и отменах
- 🛠 Команда `/admin` для владельца: список ближайших записей
- ℹ️ Раздел «О нас и цены»
- Выходные дни и прошедшее время автоматически скрываются

## Как запустить

1. Создай бота в Telegram через `@BotFather` (команда `/newbot`) и скопируй токен.
2. Скопируй `config.example.py` в `config.py` и вставь токен в `TOKEN`.
3. Установи библиотеку: `pip3 install -r requirements.txt`
4. Запусти: `python3 bot.py`
5. Напиши боту `/id`, он пришлёт твой Telegram ID. Впиши его в `config.py` в `OWNER_ID` и перезапусти бота, чтобы получать уведомления о записях.

## Как переделать под другого заказчика

Все настройки лежат в начале файла `bot.py`, раздел «Настройки»: название, адрес, телефон, список услуг и цен, часы работы, выходные дни, на сколько дней вперёд можно записаться. Менять код логики не нужно.

## Технологии

Python 3, библиотека pyTelegramBotAPI, хранение записей в JSON-файле.
